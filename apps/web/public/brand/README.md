# Vellistry logo concepts (SVG adaptations)

Status: **Proposed visual assets — owner review required**.

These SVG files are newly constructed vector adaptations of the chosen Vellistry V / fountain pen / quill visual direction, **not byte-identical copies of the original AI-generated PNG images**. Their design, proportions and typography may differ slightly. Do not represent them as approved final brand masters until reviewed.

| Asset | Proposed use |
|---|---|
| `logo-stacked-light.svg` | Landing page, introduction, promotional artwork on white |
| `logo-horizontal.svg` | Website header and navigation |
| `app-icon.svg` | PWA home-screen/icon artwork |
| `logo-stacked-dark.svg` | Dark sections and splash artwork |
| `logo-monochrome.svg` | Single-color print, watermarks, simple backgrounds |
| `mark.svg` | Icon-only mark for compact interfaces |
| `pwa-maskable.svg` | Full-bleed PWA tile with safe-zone-centered mark |

Use the originals from the conversation for final visual comparison. The original raster PNG variants and practical 192 px/512 px PNG exports are in the separately delivered Vellistry brand-assets package and were not uploaded by this GitHub change. Do not claim `favicon.ico`, Apple touch icons or required PNG manifest assets have been deployed by this PR. Their import, device review, and browser testing remain separate work.

No application source files are changed by this asset proposal.
