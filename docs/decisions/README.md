# Decision records

Architecture decision records reside here. Every file must include YAML front matter conforming to [the schema](../governance/RECORD-SCHEMAS.md). Use stable `ADR-NNNN` IDs and record alternatives, reasoning, consequences, evidence, related requirements/contracts, approval, and supersession.

**Accepted is not implemented.** Do not silently change an accepted ADR to reflect a later plan. Create a superseding ADR with bidirectional links when the decision itself changes.
