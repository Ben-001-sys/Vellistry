# Historical event — initial Vellistry MVP scope approved

## Event

On **9 October 2026**, the Vellistry project owner **explicitly accepted** the first eight-area MVP proposal with the reply **“I agree.”** The accepted proposal combined ordinary book/chapter writing; a Tiptap 3 editor; durable saving/portability; manual and AI-assisted, author-approved live character/storyline profiles; the source-frozen, user-controllable Rules Studio; limited BYOK AI Continue/Rewrite; reversible suggestion review; and privacy/accessibility baseline.

The approval also encompassed the specific prior request to **postpone the complete native Cover Studio and professional EPUB/print publishing** beyond the first writing-focused product, **not** to remove them from Vellistry's broader vision.

## Prior state and resulting state

**Before:** R04 compared A editor-only, B controlled AI, C complete book studio, then recommended one bounded first MVP integrating live profiles. All 396 inventory rows were previously unprioritized; neither product MVP nor launch architecture was approved.

**After:** The eight-area initial product target, staged A → B+ → validated public MVP delivery, and explicit Cover Studio / professional publication deferral became an **owner-approved product scope**. Implementation and release readiness remain unproven. The actual service stack, model provider, DOCX conversion library and production data layout remain undecided.

## Interpretation and limits

This is evidence of a **product-scope decision**. It does not prove that a real writer tested the application, that the default rule pack is certified, that the app has been built, that it is secure, or that a subscription/provider was chosen. Future research may require an explicit revised scope decision, without rewriting this original event.
