# Historical knowledge

Historical events are recorded here with mandatory metadata, using IDs such as `HIS-20261008-001`. See [RECORD-SCHEMAS.md](../governance/RECORD-SCHEMAS.md).

An event describes what occurred and its evidence. Interpretations and proposals are explicitly separate. Event time must not be invented. Corrections should be additive and traceable rather than silent rewrites.
